Painel Estratégico: Economia e Política da China (2023–2035)
Bem-vindo ao repositório do Observatório Econômico e Político da China. Este projeto reúne uma aplicação web interativa (`index.html`), uma base de dados estruturada (`DADOS_ECONOMIA_CHINA.md`) e um caderno analítico de fontes (`CADERNO_PESQUISA_NOTEBOOK.md`) sobre o modelo de desenvolvimento chinês sob as diretrizes do Partido Comunista da China (PCC).
---
📂 Estrutura de Arquivos do Repositório
O repositório foi dividido de forma modular para separar a documentação técnica, os dados brutos e a síntese teórica de pesquisa:
```text
├── index.html                      # Painel web interativo (cores da China/PCC + acessibilidade)
├── README.md                       # Documentação do repositório e guia de publicação
├── DADOS_ECONOMIA_CHINA.md         # Base completa de tabelas, indicadores e projeções (2023–2035)
└── CADERNO_PESQUISA_NOTEBOOK.md    # Síntese teórica, jurídica, links oficiais e guia para Notebook
```
---
🖥️ Recursos do Painel Web (`index.html`)
O arquivo `index.html` foi desenvolvido em arquivo único (Single-File Application), sem dependência de bibliotecas externas, garantindo carregamento instantâneo e total compatibilidade com o GitHub Pages:
Identidade Visual Temática (China & PCC):
Construído com a paleta institucional vermelha (`#8B0000` / `#DE2910`) e amarela/ouro (`#FFDE00`).
Acessibilidade Integrada (Padrão WCAG):
Controle de Fonte: Botões `A-`, `A` e `A+` na barra superior fixa para redimensionar todo o texto do painel;
3 Modos de Visualização: Alternância imediata entre Padrão PCC (Vermelho/Ouro), Fundo Claro e Alto Contraste (WCAG AAA);
Navegação Assistiva: Suporte integral a teclado (`Tab`, `Enter`), skip-link ("Pular para o conteúdo principal") e marcação semântica `ARIA`.
Didática e Leitura Rápida:
Caixas de resumo "Como entender em 30 segundos" no topo de cada módulo, traduzindo conceitos técnicos para linguagem acessível.
Seis Módulos Interativos:
Aba 1: Panorama Macroeconômico, Dinâmica Trimestral (2026) e Projeções (2023–2028);
Aba 2: Filtro interativo com os 20 indicadores do 15º Plano Quinquenal (2026–2030);
Aba 3: Simulações Estruturais para 2035 (Modelo DRCCGE), IA, Semicondutores e Dados como Capital;
Aba 4: Crise Imobiliária, Dívida Oculta de Governos Locais (LGFVs) e Novo Mecanismo de PPPs;
Aba 5: Transição Demográfica, Seguros Públicos de Saúde e Impactos para o Brasil;
Aba 6: Ala de Termos Técnicos com busca em tempo real e links diretos a partir do texto.
